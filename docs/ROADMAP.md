# Roadmap

## v0.4.1 — catalog-first course correction

- Make product discovery/sourcing the primary project purpose.
- Keep benchmark harness as optional evidence tooling.
- Separate included/fixed RAM from board/CPU maximums.
- Add explicit performance provenance/confidence vocabulary.
- Add catalog browsing/filtering/show commands.
- Add conservative model-weight capacity screening without fake tokens/sec.
- Reframe scoring as a buying/research shortlist.

## v0.5 — automated catalog and decision intelligence

- asynchronous source adapters for product/price discovery;
- listing freshness/disappearance/reappearance detection;
- historical prices and source-health history;
- CAD conversion and Canada landed-cost estimates;
- normalized seller/availability/configuration confidence;
- source retry/backoff/rate-limit budgets;
- autonomous daily/weekly refresh profiles;
- configurable watchlists and change alerts;
- sourced vendor/community performance evidence ingestion;
- strict compatible benchmark aggregation/change detection;
- first-class discrete GPU sourcing across CUDA, ROCm/Vulkan and oneAPI/SYCL ecosystems;
- GPU-specific fixed-VRAM and board-power semantics;
- native-currency all-time-low detection;
- price trend and volatility analysis;
- opportunity freshness/expiry;
- P1-P4 alert prioritization;
- ranked Buy / Watch / Ignore / Experimental daily recommendations.

## v0.6 — deeper ownership-cost and decision support

- exact host/RAM/PSU/cooling total-cost calculation for GPUs and host-attached accelerators;
- historical landed-CAD snapshots so FX-driven changes are preserved at observation time;
- province/tariff/HS-code evidence with explicit uncertainty;
- confidence-aware multi-source performance ranges only for compatible real measurements;
- product comparison pages and longitudinal change history;
- notification delivery adapters after evidence/alert generation;
- additional structured used-market and distributor coverage where official/legal access exists;
- broader GPU coverage including workstation/datacenter cards when used prices make them relevant.

## Optional measurement track

- benchmark the ThinkPad L14 as a local reference;
- accept contributed normalized benchmark results;
- collect exact-GPU and exact-board results with model/runtime/power-boundary provenance;
- never require local ownership for catalog inclusion;
- never let benchmark work displace catalog/product work.
