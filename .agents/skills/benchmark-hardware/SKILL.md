# Optional Hardware Benchmark Skill

Use only when importing reproducible benchmark evidence or testing hardware a contributor actually has. Benchmarking is **not required** to add a catalog product.

1. Read `specs/BENCHMARKING.md`, `specs/EVIDENCE.md` and `docs/BENCHMARK_HARNESS.md`.
2. Prefer `llm-cluster-bench` machine-readable records over pasted numbers.
3. Preserve model/runtime/hardware identity, raw output and workload dimensions.
4. Keep prefill/decode and specialist workload metrics separate.
5. Complete-node input power is required for canonical tokens/joule; chip/TDP data stays descriptive.
6. Imported vendor/community results must preserve source URL and confidence.
7. Do not let benchmark availability gate catalog inclusion or catalog-first shortlist scoring.
