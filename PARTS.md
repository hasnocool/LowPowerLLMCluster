### AMD / ASRock BC-250 specialty compute board, 16GB unified GDDR6

The BC-250 is the weird bargain worth tracking. It combines CPU and GPU access to 16GB of very fast GDDR6, which can make it surprisingly attractive for Vulkan inference. The tradeoff is significant: firmware, cooling, power delivery, Linux setup and GPU support are community-driven rather than plug-and-play. Treat every benchmark as board/revision/software specific and never assume a 40-CU unlock is safe or functional on every unit.

- Vendor/source: secondary-market / decommissioned mining hardware
- Hardware class: salvaged_accelerated_apu_board
- Software maturity: experimental_vulkan
- Risk: high
- Verified: 2026-08-10
- Source/listing: https://www.aliexpress.us/item/3256808465406873.html

### NVIDIA Jetson Orin Nano Super Developer Kit, 8GB

This is one of the cleanest efficiency references in the catalog. NVIDIA gives it a mature CUDA/TensorRT/JetPack stack, and the board can run in a 7-25W envelope. The catch is memory: 8GB makes it excellent for small LLMs, embeddings, vision and control-plane AI, but it is not a replacement for a 32-96GB x86 node when model capacity is the goal.

- Vendor/source: NVIDIA
- Hardware class: edge_ai_developer_kit

### Orange Pi 5 Plus, RK3588, 32GB LPDDR4X

### Intel N100 dual-LAN mini PC / control-plane node

Do not buy an N100 because it looks good at LLM generation. Buy it because an always-on router, scheduler, monitoring node and model registry should consume very little energy and should not steal RAM or CPU time from inference workers. Keeping the control plane separate also makes the cluster more resilient.

- Vendor/source: Alibaba multi-vendor market
- Hardware class: ultra_low_power_x86
- Software maturity: mainstream_linux
- Risk: low
- Verified: 2026-08-10
- Source/listing: https://electronics.alibaba.com/product/n100-mini
